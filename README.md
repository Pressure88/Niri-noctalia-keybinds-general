# niri-keybinds-manager

Small Python CLI tool to view and edit niri keybindings.

## Features
- Parse ~/.config/niri/cfg/keybinds.kdl
- Show keybinds grouped by category (browser, terminal, screenshot, ...)
- Search binds by keyword
- Edit a keybinding in-place, preserving file formatting

## Requirements
- Python 3.9+
- niri (for the config file path)

## Usage
python main.py
